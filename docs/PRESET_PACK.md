# The Sound Pack: 1 000 presets

`crates/engine/src/presets/pack.rs` holds 1 000 presets in ten categories (100 each), after the
91 hand-made M9 presets. The file is generated by `crates/engine/examples/gen_preset_pack.rs`:

```
cargo run --release -p engine --example gen_preset_pack
```

To change the pack, edit the archetypes or variations in the generator and run it again. Do not
edit `pack.rs` by hand. The output is deterministic.

## Where the sounds come from (research and licensing)

BeatSlopper is `MIT OR Apache-2.0`, so every preset it ships must be ours to license that way.
Before writing any patches we checked what open preset material exists:

| Source | Licence | Usable here? |
| --- | --- | --- |
| Surge XT factory patches (about 2 800, github.com/surge-synthesizer/surge) | The project is GPL-3.0. No separate permissive grant for the patches was found. | No: copyleft, and Surge's parameters (wavetables, several oscillator types, multiple filter models) do not map onto this engine. |
| Other open-source synth banks (ZynAddSubFX / Yoshimi, Helm, OB-Xf, Odin 2) | GPL-family. Licences unverified preset by preset. | No: same reasons. |
| Vital, Serum, Massive and other commercial factory banks | Proprietary. | No. |
| DX7 ROM cartridges (as used in Dexed) | Yamaha's data, unclear status. | No. |
| Meadowlark factory library (github.com/BillyDM/meadowlark-factory-library) | CC0. | Nothing to use: it holds samples, and its README says it has no synth presets yet. |
| Public-domain SoundFont banks (polyphone.io) | Listed as public domain. | Not applicable: these are sample-based, not synth parameter data. |

There is no permissively licensed synth preset bank we could import, and no third-party patch
format maps onto BeatSlopper's 58 parameters anyway (two oscillators, unison, sub, noise,
one FM operator, a Karplus-Strong string, a multimode SVF with ADSR, one LFO, a pitch envelope,
and the drive / lo-fi / chorus / sidechain insert plus delay and reverb sends).

So the pack is **original work**, built from documented synthesis techniques. A technique is
not copyrightable, unlike a particular patch file. Examples:
- A bowed string is a saw with a slow attack.
- Brass is detuned saws behind a filter envelope that opens with the breath.
- A clarinet is a square wave, because its closed bore gives odd harmonics.
- A bell is FM at an inharmonic ratio.
- A guitar is a Karplus-Strong plucked string.

These are textbook subtractive and FM recipes (for example Roland's and MusicTech's synth
programming guides, and Chowning's FM work). They were applied here without copying any
values from anyone's presets. **No third-party patch data is in this repository.** The pack is
covered by the project's `MIT OR Apache-2.0` licence like the rest of the code.

## How it is built

1. **Templates**, one per category: the settings its sounds share. For example, struck keys
   get a fast attack and a long decay into a low sustain, and organs get a gate-shaped amp.
2. **Archetypes**, about 145 of them, 13 to 17 per category. Each is one recipe and has a
   comment in the generator that explains it, e.g. "Oboe: a narrow pulse through a resonant
   band-pass (the nasal double reed)".
3. **Variations**, 21 of them. Each changes several parameters in a musically meaningful
   way, and each has its own rule for which sounds it may apply to:
   - Dusty: lo-fi, vinyl, wobble.
   - Wide: chorus plus unison.
   - Bright / Velvet: filter and pick brightness.
   - Cathedral: hall, slower envelopes.
   - Tape: wow and flutter.
   - Driven: amp drive.
   - Echoing: an eighth-note echo.
   - Soft: slow, velocity-sensitive attack.
   - Pumping: sidechain.
   - Vintage: drift plus slight vibrato.
   - Crystal: FM sparkle.
   - Gliding: portamento.
   - Staccato.
   - Bitcrushed.
   - Drifting: slow filter LFO.
   - Airy: breath noise.
   - Singing: vibrato.
   - Deep: sub octave.
   - Fingerpicked and Ringing: guitars only.

   A variation is skipped where it would not change the sound: no unison or FM on a plucked
   string, no glide on a bell, no sidechain on a bell.
4. **Selection.** Every archetype gives its plain version first, then its fitting variations
   in an order rotated by its position, so all variations show up across a category.
   Candidates are taken round-robin until the category holds 100.
5. **Every candidate is rendered through the engine before it is accepted:**
   - **Loudness:** the loudest 200 ms RMS of a held note at velocity 0.8 (C2 for basses, E3 for
     guitars, C4 otherwise) is brought to -18 dBFS. The oscillator mixes are scaled; for a
     plucked string Osc 1's mix is the string's level. When the mixes are already at full,
     gentle drive is added as make-up gain. The candidate is kept only inside -27 .. -11 dB.
     The checked-in pack sits between -21 and -16 dB.
   - **The tests/presets.rs contract, with margin:** finite, audible at C4, peak at most 0.98,
     and silent (or down to its own vinyl bed) within 6 s of release. The tests allow 8 s.
   - **A unique name**, case-insensitive, across the whole library and the eight classics.
   - **At least four track parameters different** from every other preset in the library.
6. Names are `<Variation> <Archetype>`, e.g. "Dusty Felt Piano" or "Cathedral Church Organ".
   Tags merge the archetype's tags (instrument, genre, mood) with the variation's (`lofi`,
   `wide`, `sidechain`, ...), so search finds "piano", "brass", "8bit", "pumping" and so on.

## Guitars: the level fix that came with the pack

Before this change, the plucked-string (Karplus-Strong) voice was 14 dB under the keys on
average (the lofi guitar category at -34 dBFS, Nylon Guitar at -44). The excitation is one
period of noise, which spreads its energy over every harmonic up to Nyquist, and the loop
lowpass removes most of it within a few trips round the loop. Dull or low strings therefore
came out 20 dB or more under bright ones, and every pluck drew a different random level.

`Pluck::pluck` now measures each burst after the loop lowpasses it would go through in its
first 30 ms. It scales the burst to a fixed level and soft-clips the scaled burst so a bright
pick into a damped string does not spike. A re-pluck halves the period it lands on first, as
a pick damps a ringing string, so fast repeated notes stay within a few dB of a single hit
instead of piling up. The voice multiplies the string by Osc 1's mix,
which every existing pluck preset already set to 1.0. As a result:
- Across damping, brightness and C2..C5, a pluck's first 300 ms now stays within about
  ±5 dB.
- Different noise draws of the same pluck sound alike.
- The lofi guitars now sit at the pack's level (median -18 dB, at or above the lofi keys).
- The pack guitars sit with the pack keys.

`tests/presets.rs::guitars_are_as_loud_as_keys`, `repeated_plucks_do_not_pile_up` and
`synth::pluck::tests::pluck_level_is_consistent_across_settings_pitches_and_draws` hold all of
this.
